## Requisitos no funcionales

| ID | Categoría | Requisito |
|---|---|---|
| RNF-01 | Eficiencia de desempeño | El sistema debe cargar cada pantalla en un máximo de 3 segundos en el 90 % de las solicitudes, con una conexión de 10 Mbps. |
| RNF-02 | Eficiencia de desempeño | El sistema debe confirmar el guardado de una respuesta, un borrador, una entrada de diario o un check-in de seguridad en un máximo de 2 segundos en el 90 % de los envíos. |
| RNF-03 | Eficiencia de desempeño | El sistema debe mostrar la retroalimentación de gamificación (desbloqueos, logros, nivel, afinidad y amistad con el asistente) en un máximo de 2 segundos después de completarse la acción que la origina, en el 90 % de los casos. |
| RNF-04 | Eficiencia de desempeño | El sistema debe obtener del servicio de LLM la evaluación de una respuesta de registro, con su pregunta de seguimiento cuando corresponda, en un máximo de 10 segundos en el 90 % de las solicitudes, con hasta 10 solicitudes simultáneas. |
| RNF-05 | Capacidad de interacción | El sistema debe mostrar todas sus pantallas sin desplazamiento horizontal en anchos de pantalla desde 360 px. |
| RNF-06 | Capacidad de interacción | El sistema debe mostrar la retroalimentación de gamificación y los mensajes del asistente sin interrumpir ni reiniciar la actividad en curso, y permitir cerrarlos con una sola acción. |
| RNF-07 | Fiabilidad | El sistema debe conservar, ante un cierre inesperado, la posición alcanzada en cada actividad y todas las respuestas del estudiante, salvo la del ítem que estaba respondiendo. |
| RNF-08 | Fiabilidad | El sistema debe seguir funcionando sin mostrar errores al usuario cuando el servicio de LLM no responda en 15 segundos, devuelva un error o entregue una respuesta con formato inválido. |
| RNF-09 | Seguridad | El sistema debe cifrar todas las comunicaciones mediante HTTPS con TLS 1.2 o superior. |
| RNF-10 | Seguridad | El sistema debe almacenar las contraseñas con un algoritmo de hash con sal, como bcrypt o Argon2. |
| RNF-11 | Seguridad | El sistema debe verificar en el servidor, en cada solicitud, que el usuario tenga permiso sobre la pantalla o el dato solicitado según su rol y los estudiantes que tiene asignados o vinculados. |
| RNF-12 | Seguridad | El sistema debe mostrar el contenido de las entradas del diario únicamente a su autor. |
| RNF-13 | Seguridad | El sistema debe enviar al servicio de LLM únicamente la información necesaria para cada solicitud, sin nombres ni otros datos que identifiquen al estudiante: para evaluar una respuesta, la consigna y los criterios del ítem, las opciones elegidas, las respuestas del estudiante en la misma actividad y el texto por evaluar; para consolidar una respuesta, la consigna del ítem, su texto inicial y las respuestas de seguimiento; para personalizar una entrada de diario, solo los datos que esa entrada declara; para generar la pregunta del día, el avance del estudiante por temática en su recorrido. |
| RNF-14 | Seguridad | El sistema debe tratar el texto del estudiante como dato y no como instrucción en las solicitudes al servicio de LLM, y aceptar solo respuestas que cumplan el esquema definido. |
| RNF-15 | Seguridad | El sistema debe conservar sin modificaciones el registro de cada evaluación de una respuesta de registro, con su origen (servicio de LLM o extensión mínima), para que pueda auditarse. |
| RNF-16 | Mantenibilidad | El sistema debe representar todas las actividades, sean informativas, de registro o de cuestionario, mediante una misma estructura compuesta por una secuencia de momentos, como un texto, un video o un ítem. |
| RNF-17 | Mantenibilidad | El sistema debe permitir modificar las actividades y los instrumentos mediante archivos de configuración, sin modificar el código fuente. |
| RNF-18 | Mantenibilidad | El sistema debe permitir modificar los criterios de completitud de los ítems, las listas de opciones, los mensajes de retroalimentación y de bloqueo, las preguntas del diario, las reglas de desbloqueo, las condiciones de los logros, los requisitos de los niveles, las reglas y redacciones de los temas para conversar y los umbrales de las alertas mediante archivos de configuración, sin modificar el código fuente. |
| RNF-19 | Mantenibilidad | El sistema debe determinar los desbloqueos de bloques, actividades, secciones, campos de las tarjetas de carrera, preguntas del diario, fichas, testimonios, conversaciones, logros y niveles mediante un mismo mecanismo de reglas evaluadas sobre el registro de eventos de uso. |
| RNF-20 | Seguridad | El sistema debe resolver los datos del estudiante que muestra o usa una actividad o una entrada de diario únicamente a partir de un catálogo cerrado de tipos de referencia, cada uno limitado a los datos de la propia cuenta. |

## Glosario

| Término | Definición |
|---|---|
| Actividad | Unidad de trabajo de la plataforma, compuesta por una secuencia de momentos. Puede ser informativa, de registro, de cuestionario, un caso o una batalla. Puede ser requerida u opcional. |
| Momento | Paso de una actividad: un diálogo del asistente, un contenido, un ítem o una pregunta de comprobación. |
| Asistente | Personaje guía de la plataforma que acompaña al usuario con diálogos y mensajes. |
| Bloque | Conjunto de actividades de una ruta o de las actividades libres. |
| Ruta | Secuencia de actividades de un usuario. El estudiante y el apoderado tienen rutas distintas. |
| Sección | Parte de la plataforma que la ruta invita a usar (catálogo, planes, diario, check-in, familia e investigaciones). Se desbloquea al completar una actividad y desde entonces permite registrar. |
| Actividad hito | Actividad de la ruta del estudiante (1.3 Lo que esperan de mí) que, al completarse, habilita la ciudad, la sección de familia y las conversaciones. |
| Actividades libres | Actividades de la ciudad que el estudiante puede realizar en el orden que elija una vez completada la actividad hito. |
| Actividad requerida | Actividad del camino que cuenta para el avance requerido. Las opcionales, las de la ciudad y las misiones adicionales no cuentan. |
| Actividad informativa | Actividad que presenta contenido (diálogos, textos, videos o datos) y solo registra su completitud. Puede incluir preguntas de comprobación. |
| Pregunta de comprobación | Pregunta de opción múltiple de una actividad informativa, con una explicación para cada opción incorrecta. |
| Batalla | Actividad de preguntas con vidas que comprueba lo aprendido en las informativas. Puede repetirse; solo el primer intento cuenta para la métrica de conocimiento. |
| Misión adicional | Actividad opcional que aparece en el mapa cuando una actividad de registro queda con todas sus respuestas adecuadas. |
| Ficha | Contenido informativo que se desbloquea al completar determinadas actividades y que puede consultarse después. |
| Actividad de registro | Actividad de hasta tres ítems que el estudiante responde eligiendo opciones, cuando el ítem las tiene, y escribiendo un texto. La orientadora ve cada ítem con lo elegido y lo escrito. |
| Ítem | Pregunta o consigna de una actividad. |
| Ítem núcleo | Ítem de una actividad de registro cuya respuesta recibe con prioridad la pregunta de seguimiento. |
| Lista de opciones | Catálogo fijo de opciones con código, como las rutas después del colegio o las dificultades. Una lista común se usa en varias actividades y en las tarjetas de carrera, lo que permite comparar respuestas de distintos momentos. |
| Referencia | Dato del estudiante que una actividad o una entrada de diario lee de la plataforma (sus planes, favoritos, resultados, una respuesta de registro anterior o su respuesta a un ítem de cuestionario) para ofrecerlo como opciones, marcar una opción, nombrarlo, citarlo o mostrarlo como contexto. |
| Criterio de completitud | Aspecto que debe abordar una respuesta de registro, como un ejemplo concreto, una razón, una acción, un contraste o una extensión mínima. Cada ítem de registro tiene cero o más; un ítem sin criterios se acepta como adecuado sin evaluarse. |
| Servicio de LLM | Servicio externo de modelo de lenguaje (p. ej., Gemini) que evalúa si una respuesta de registro cubre los criterios de su ítem, redacta la pregunta de seguimiento, consolida la respuesta, personaliza algunas entradas del diario y genera la pregunta del día. |
| Pregunta de seguimiento | Pregunta que el sistema formula, al entregar una actividad de registro, sobre los criterios que una respuesta no cubre. Hay como máximo dos por actividad, primero en su ítem núcleo; un mismo ítem puede recibir las dos mientras su respuesta, con lo ya respondido, siga poco desarrollada. El estudiante puede responderlas u omitirlas. |
| Clasificación de la respuesta | Resultado de evaluar la respuesta de un ítem de registro, con sus respuestas de seguimiento: adecuada, poco desarrollada o no evaluada. Solo la poco desarrollada deja de citarse en otras actividades y de contar para las misiones adicionales. |
| Respuesta consolidada | Texto de un ítem de registro que integra la respuesta inicial y las respuestas de seguimiento, redactado por el servicio de LLM sin agregar ideas propias. Sin seguimiento, es la respuesta inicial. Es la que se cita en otras actividades y la que lee la orientadora. |
| Respuesta que requiere atención | Respuesta de registro que el servicio de LLM marca por su contenido para que la orientadora la revise. El estudiante no ve la marca. No se usa en la primera versión de la plataforma. |
| Extensión mínima | Cantidad mínima de caracteres de una respuesta de registro. Puede ser un criterio del ítem, que se evalúa sin el servicio de LLM, y es el respaldo cuando el servicio no está disponible: por debajo de ella, el sistema formula la pregunta de seguimiento genérica del ítem. |
| Borrador | Respuesta de registro guardada sin enviar, que el estudiante puede retomar. |
| Actividad de cuestionario | Actividad compuesta por ítems de opción de un instrumento. Un instrumento puede repartirse en varias actividades. |
| Instrumento | Definición de un cuestionario con sus ítems, escalas, dimensiones y tipo de resultado. |
| Tipo de resultado | Forma en que un instrumento calcula su resultado: dimensiones destacadas, ocupaciones afines o comparación entre la aplicación de entrada y la de salida, por dimensión y por ítem. |
| Cuestionarios de autoconocimiento | Cuestionarios cuyo resultado describe al estudiante. Sus resultados los ven el estudiante, la orientadora y el apoderado, este último solo cuando completó su ruta y si la orientadora marcó el cuestionario como visible. |
| Cuestionarios de entrada y de salida | Cuestionario de punto de partida (0.3) y de punto de llegada (5.2): las mismas 19 afirmaciones en cinco dimensiones. Sus resultados por dimensión y sus respuestas ítem por ítem solo los ven el estudiante y la orientadora. |
| Zona de una dimensión | Lectura del promedio de una dimensión del cuestionario de punto de partida o de llegada: zona fuerte, en camino o zona por trabajar. |
| Vista resumida y vista explicada | Formas de presentar el resultado de un cuestionario: la resumida muestra los rasgos predominantes; la explicada, su interpretación. |
| Revelar un resultado | Acción del estudiante en el libro de Helena, habilitada al completar todas las misiones de un cuestionario, que calcula y muestra su resultado. Hasta entonces nadie más lo ve. |
| Test de intereses | Cuestionario de intereses vocacionales basado en RIASEC; es uno de los cuestionarios de autoconocimiento. |
| Ocupaciones afines | Ocupaciones cuyo perfil coincide con el resultado del test de intereses. Cada una se relaciona con las carreras que conducen a ella. |
| Perfil plano | Resultado del test de intereses en el que todos los tipos tienen el mismo puntaje y no hay ocupaciones afines. El estudiante puede volver a realizar el test. |
| Coincidencia con el test de intereses | Proporción de las carreras y ocupaciones favoritas del estudiante que figuran entre sus ocupaciones afines o entre las carreras que conducen a ellas. |
| Temática | Cada una de las cinco dimensiones del cuestionario de punto de partida y de llegada (claridad, conocimiento de mí, conocimiento de las opciones, decisión propia y confianza), compartidas por actividades, fichas, testimonios e ítems de cuestionario. |
| Entrada desbloqueada | Pregunta del diario predefinida que se habilita al completar una actividad o una conversación. Puede ser fija o personalizada por el servicio de LLM con los datos que la entrada declara. |
| Pregunta del día | Pregunta para el diario que el servicio de LLM genera cada día para cada estudiante a partir de su avance por temática. Si el servicio no responde, se toma de un banco de preguntas predefinidas. |
| Amistad con el asistente | Indicador que aumenta conforme el estudiante registra entradas en su diario. Nunca disminuye. |
| Check-in de seguridad | Valoración diaria del estudiante, en una escala de 1 a 5, de su seguridad frente a la decisión vocacional. |
| Favorito | Carrera, ocupación o institución que el estudiante marca para seguir explorándola. |
| Tarjeta de carrera | Desarrollo de una carrera por el estudiante: motivo principal y motivación, trayecto previsto, listas de fortalezas, debilidades, oportunidades y obstáculos, presupuesto, acciones de preparación, medidores y prioridad. Hay una por carrera y hasta tres. Sus campos se habilitan a medida que avanza el camino. |
| Medidores del plan | Tres valoraciones del estudiante sobre cada tarjeta de carrera: cuánto le entusiasma, qué tan capaz se siente y si tiene cómo lograrlo. |
| Opción inicial | Carrera del primer plan que registra el estudiante antes de completar el Bloque 1. Si no registra ninguno, el informe dice «sin opción inicial». |
| Presupuesto | Estimación del costo de estudiar la carrera de una tarjeta en una institución que la ofrece: cada gasto con su rubro (matrícula, pensión, materiales, transporte, vivienda u otros), su monto y su frecuencia, y cómo se financiaría. |
| Caso | Actividad libre en la que el estudiante asigna ocupaciones a los problemas de unos personajes sin exceder un presupuesto. |
| Ícono de ocupación | Distintivo de una ocupación que se desbloquea al asignarla correctamente en un caso superado. |
| Testimonio | Relato de una trayectoria real de estudio o de trabajo, que se desbloquea al resolver un caso. Mientras está bloqueado muestra solo su pista. |
| Entrevista | Video de un estudiante a un profesional sobre una ocupación, hecho con un guion fijo y publicado con un resumen y, opcionalmente, con coautores. La ven el salón de sus autores y sus orientadoras. |
| Reacción | Valoración de un estudiante a la entrevista de un compañero: «Aprendí algo» o «Me gustó cómo se realizó», con un comentario sobre esa reacción, obligatorio si aprendió algo. |
| Leyenda | Entrevista que alcanzó el mínimo de reacciones y fue destacada por la orientadora. La ven todas las aulas y las promociones siguientes. |
| Conversación guiada | Conversación en casa entre el estudiante y su apoderado sobre un tema, con una guía de preguntas, que se marca como sostenida. El apoderado ve todas las guías al completar su ruta; el estudiante las habilita una por una, y solo se puede marcar como sostenida una conversación que el estudiante ya tiene habilitada. |
| Carta | Mensaje que el estudiante y el apoderado se escriben. Cada uno lo escribe para habilitar sus conversaciones y lo recibe cuando completan todas sus conversaciones. |
| Evento de uso | Acción de un usuario que el sistema registra con fecha y hora, como ingresar, completar una actividad o escribir en el diario. |
| Regla de desbloqueo | Conjunto de condiciones sobre los eventos de uso que, al cumplirse, desbloquea un contenido o un logro para una cuenta. |
| Logro | Insignia que se obtiene al cumplir una regla de desbloqueo. Los logros ocultos no muestran su condición hasta obtenerse. |
| Nivel | Etapa del proceso en la que se encuentra el estudiante según los requisitos cumplidos. |
| Afinidad | Indicador que aumenta con cada actividad libre distinta completada. |
| Avance por temática | Proporción de actividades completadas entre las actividades asociadas a cada temática. |
| Diploma | Reconocimiento que obtiene el apoderado al completar su ruta. |
| Alerta | Aviso que el sistema genera para la orientadora en cuanto un estudiante cumple una condición predefinida: sin ingresar en varios días, familia sin registrar o sin ruta, seguridad baja sostenida, avance bajo el del salón, sin favoritos o carrera del plan principal fuera de las recomendadas por su test de intereses. |
| Prioritario | Actividad de registro o cuestionario que la orientadora marca para su salón para verlo destacado en el perfil de sus estudiantes. Los cuestionarios prioritarios son además requisito del Bloque 4. |
| Configuración del salón | Registros y cuestionarios prioritarios del salón y cuestionarios que puede ver el apoderado, definidos por su orientadora. |
| Bitácora de viaje | Página del estudiante que reúne, a medida que recorre la ruta, quién es, sus planes, de dónde partió y qué exploró, sus respuestas de registro y los temas para conversar. |
| Informe de viaje | La bitácora entregada al terminar el camino (5.4). Es la base de la conversación con la orientadora; se puede imprimir o exportar a PDF. |
| Tema para conversar | Situación detectada por una regla sobre los datos del estudiante, con una redacción explícita para la orientadora y otra tranquila para el estudiante. |
| Perfil del estudiante (orientadora) | Vista de la orientadora con el informe de viaje de un estudiante, que destaca los cuestionarios y las actividades de registro que ella marcó como prioritarios. |
